# Steam Scout Bot

Telegram бот для поиска выгодных предложений в Steam (скидки и бесплатные игры).

## 1. Название и назначение сервиса

**Steam Scout Bot** — это телеграм-бот, который помогает пользователям находить актуальные скидки и бесплатные раздачи в магазине Steam. Бот автоматически отслеживает новые бесплатные игры и уведомляет подписчиков.

**Основные функции:**
- Вывод списка игр со скидками (команда `/sale`)
- Вывод списка бесплатных игр (команда `/free`)
- Поиск игры по названию в распродажах (команда `/search`)
- Подписка на уведомления о новых бесплатных играх (команда `/subscribe`)
- Автоматическая рассылка уведомлений подписчикам

## 2. Архитектура и зависимости

### Технологии и фреймворки:

| Технология | Назначение |
|------------|------------|
| PHP 8.2+ | Язык программирования |
| Laravel 12 | PHP фреймворк |
| Telegram Bot SDK | Работа с Telegram API |
| GuzzleHTTP | HTTP-клиент для запросов к API |
| SQLite | База данных для хранения подписчиков |
| Docker | Контейнеризация приложения |

### Взаимодействие с внешними API:

| Сервис | Эндпоинт | Описание |
|--------|----------|----------|
| Steam API (прокси) | `/steam/sales` | Получение списка игр со скидками |
| Steam API (прокси) | `/steam/free` | Получение списка бесплатных игр |
| Telegram Bot API | `api.telegram.org` | Отправка и получение сообщений |

### Инструменты разработки:

| Инструмент | Назначение |
|------------|------------|
| Laravel Pint | Автоматическое исправление стиля кода (Code Style Fixer) |
| PHPStan | Статический анализ кода (Линтер) |
| PHPUnit | Модульное и интеграционное тестирование |

## 3. Способы запуска сервиса

### Требования:
- PHP 8.2+
- Composer
- Docker (опционально)
- Git

### Локальный запуск (без Docker):

```bash
# 1. Клонирование репозитория
git clone https://github.com/paparadwa/steam-scout-bot.git
cd steam-scout-bot

# 2. Установка зависимостей
composer install

# 3. Создание .env файла
cp .env.example .env

# 4. Генерация ключа приложения
php artisan key:generate

# 5. Создание базы данных SQLite
mkdir database && touch database/database.sqlite

# 6. Запуск бота (Long Polling режим)
php artisan bot:poll
```
Запуск через Docker:
```bash
# Сборка образов
docker-compose build

# Запуск всех сервисов
docker-compose up -d

# Просмотр логов
docker-compose logs -f bot

# Остановка
docker-compose down
```
Переменные окружения (.env):
| Переменная | Описание	| Пример |
|-----------------------|-----------------------|-----------------------|
| TELEGRAM_BOT_TOKEN | Токен бота от @BotFather | 123456789:ABCdefGHIjklMNO |
| DB_CONNECTION	| Тип базы данных |	sqlite |
| DB_DATABASE | Путь к файлу БД	| /var/www/html/database/database.sqlite |

## 4. API документация
Команды Telegram бота:
| Команда | Описание |
| ------------- | --------------------------------------------------- |
| /start | Приветственное сообщение и список команд |
| /help	| Подробный список всех команд |
| /sale	| Топ-10 игр со скидками в Steam |
| /free	| Топ-10 бесплатных игр в Steam |
| /search {название} |	Поиск игры по названию в распродажах |
| /subscribe | Подписаться на уведомления о новых бесплатных играх |
| /unsubscribe	| Отписаться от уведомлений |

Внешние API (Steam):
| Эндпоинт | Метод | Описание |
| ----------------------------------------------------------- | ------ | ------------------ |
| https://eve-unputrefiable-monika.ngrok-free.dev/steam/sales | GET	| Список игр со скидками |
| https://eve-unputrefiable-monika.ngrok-free.dev/steam/free  | GET	| Список бесплатных игр |

## 5. Как тестировать
Запуск тестов:
```bash
# Запуск всех тестов
php artisan test

# Запуск конкретного тестового файла
php artisan test --filter BotCommandsTest
```
Запуск Code Style Fixer (Laravel Pint):
```bash
# Проверка стиля кода
composer pint:test

# Автоматическое исправление стиля
composer pint
```
Запуск статического анализа (PHPStan):
```bash
composer phpstan
```
Git Hook (автоматическая проверка перед коммитом):
При каждом коммите автоматически запускаются тесты. Если какой-то тест падает — коммит блокируется.
